## Description

Crumbs for Chrome saves the page you're on to your own Crumbs bookmark manager in one click.

* Fills in the title, link, favicon and description for you
* Picks the best preview image, or lets you take a screenshot or upload your own
* File it in any folder, or create a new one on the spot
* Shows when you've already saved a page
* Right-click any page, link or image to save it
* Keyboard shortcut: Alt + Shift + C

Your bookmarks stay on your own server. The extension only talks to the Crumbs address you enter in its settings.
